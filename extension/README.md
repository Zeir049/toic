# 토익 채점 & 오답노트 — 크롬 확장 프로그램

PDF 문제집을 크롬에서 띄워 두고, **바로 옆 사이드 패널**에서 답을 마킹하고, 해설지 정답을 **복사·붙여넣기**로 채점한 뒤,
틀린 문제를 **오답노트**로 정리해서 **PDF로 내보내는** 확장 프로그램입니다. 빌드 과정 없이 이 폴더를 그대로 설치합니다.

## 설치 (압축해제된 확장 프로그램 로드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택
4. (권장) 툴바의 퍼즐 아이콘에서 **토익 채점 & 오답노트**를 고정
5. (내 PC의 PDF 파일에서 *화면 캡처*를 쓰려면) 확장 프로그램 **세부정보 → 파일 URL에 대한 액세스 허용** 켜기

## 사용법

1. **PDF 열기** — PDF 파일을 크롬 창에 끌어다 놓거나 웹의 PDF를 엽니다 (크롬 기본 PDF 뷰어 사용).
2. **패널 열기** — 툴바 아이콘 클릭 또는 `Alt+Shift+T`. 패널은 탭을 옮겨도 유지됩니다.
3. **마킹** 탭
   - 시험 이름과 범위(전체 1–200 / LC 1–100 / RC 101–200 / 직접 입력)를 고릅니다.
   - 버블을 클릭하거나 키보드로 빠르게: `A–D` 또는 `1–4` 마킹 후 다음 문항으로 자동 이동, `↑↓` 이동, `⌫` 지우기.
   - 헷갈린 문항은 `F` 또는 번호 **우클릭**으로 ⚑ 표시 → 맞혀도 오답노트에 들어갑니다.
4. **채점** 탭
   - 해설지 정답을 그대로 복사해서 붙여넣습니다. 아래 형식을 자동 인식합니다.
     - `101. (B) 102. (D) …`, `101 B`, `101번 B`, `101B102D…` → 번호대로
     - `ABDCA BCDAB …` → 범위 시작 번호부터 순서대로 (`1-10:` 같은 머리말 숫자는 무시)
     - `①②③④`, `Ⓐ–Ⓓ`, 전각 `ＡＢＣＤ`
   - 인식 결과(몇 개, 범위와 몇 개 일치, 빠진 번호)를 바로 보여줍니다. 자주 쓰는 정답지는 이름 붙여 저장할 수 있어요.
   - 결과: 점수, LC/RC·파트별 정답률, 전체 답안표(빨간칸 = 내 답→정답). 마킹을 고치고 다시 채점하면 같은 기록이 갱신됩니다.
5. **오답노트** 탭
   - 채점할 때마다 기록이 쌓이고, 오답·미응답·헷갈림 문항이 자동으로 정리됩니다.
   - 문항마다 유형 태그(어휘/문법/해석/패러프레이징/듣기/시간부족/실수/함정), 메모, 복습 완료 체크.
   - 문제 이미지 첨부 3가지 방법:
     - **📷 화면 캡처**: 지금 보고 있는 PDF 화면을 찍고, 새 창에서 문제 영역만 드래그해 저장 (처음 한 번 권한 요청)
     - `Win+Shift+S`로 잘라낸 뒤 카드를 클릭하고 `Ctrl+V`
     - **🖼 이미지** 버튼 또는 카드로 파일 드래그
6. **PDF 내보내기** — 기록 하나(**PDF 내보내기**) 또는 전체(**전체 PDF 내보내기**). 인쇄용 문서가 새 탭에 열리고 인쇄 창이 뜨면
   대상을 **PDF로 저장**으로 고르면 됩니다. 메모가 없는 문항엔 손으로 쓸 수 있는 줄이 들어가고, 옵션으로 전체 답안표·헷갈림·복습 완료 문항 포함 여부를 고를 수 있어요.
7. **분석** 탭 — 약점 분석 + AI 공부법 추천
   - **약점 분석**(AI 없이 바로 계산): 전체/최근 n회 기준 정답률, LC·RC, 파트별 정답률(평균보다 낮은 파트 빨간색),
     틀린 이유 태그 통계, RC 후반 미응답(시간 부족 신호), 헷갈림 표시, 복습 완료율, 회차별 추이.
   - **AI 공부법 추천**(RAG): 아래 순서로 맞춤 학습 계획을 만듭니다.
     1. *검색(Retrieve)* — 약점 신호(약한 파트, 태그, 시간 부족, 헷갈림)와 오답 메모의 단어로
        내장 공부법 자료(`lib/kb.js`, 24개)에서 관련 자료 6개를 고릅니다.
     2. *보강(Augment)* — 약점 수치 + 최근 메모 + 고른 자료를 번호를 붙여 프롬프트에 넣습니다.
     3. *생성(Generate)* — OpenRouter 무료 모델이 진단 · 약점 TOP 3 · 공부법 · 2주 계획을 씁니다.
        공부법 문장에는 근거 자료 번호 `[1]`이 붙고, 아래 "참고한 학습 자료"에서 원문을 펼쳐 볼 수 있어요.
   - 처음 한 번 **AI 설정**에서 OpenRouter API 키를 저장하세요 ([openrouter.ai](https://openrouter.ai) 로그인 → Keys).
     모델은 기본값 `openrouter/free`(무료 모델 자동 선택)이고, 목록에서 다른 무료 모델을 고를 수 있습니다.
   - 무료 모델은 분당·일일 요청 수 제한이 있어요. 한도에 걸리면 잠시 뒤 다시 시도하거나 다른 무료 모델을 고르세요.

## 데이터

기록·오답노트·이미지는 이 브라우저의 `chrome.storage.local`에만 저장됩니다. 확장 프로그램을 삭제하면 기록도 지워집니다.

외부로 나가는 것은 **AI 공부법 추천**을 눌렀을 때뿐이며, OpenRouter로 파트별 정답률·태그 통계·최근 오답 메모(최대 10개, 각 140자)·
고른 공부법 자료만 보냅니다. 시험 이름, PDF, 이미지는 보내지 않습니다. 무료 모델은 제공사가 입력을 기록하거나 학습에 쓸 수 있으니
메모에 개인정보를 적지 마세요. API 키는 이 브라우저의 저장소에 평문으로 저장됩니다.

## 권한

| 권한 | 용도 |
| --- | --- |
| `sidePanel` | PDF 옆 사이드 패널 |
| `storage`, `unlimitedStorage` | 마킹·기록·오답노트·첨부 이미지 저장 |
| `<all_urls>` (선택 권한) | **화면 캡처** 버튼을 처음 누를 때만 요청. 거절해도 나머지 기능은 모두 동작 |

OpenRouter API는 브라우저 호출(CORS)을 허용하므로 AI 기능에 추가 권한이 필요 없습니다.

## 개발

```
extension/
├── manifest.json       # MV3
├── background.js       # 아이콘 클릭 → 사이드 패널 열기
├── sidepanel.html/css/js  # 마킹 · 채점 · 오답노트 UI
├── analysis-tab.js     # 분석 탭 (약점 프로필 + AI 추천 UI)
├── crop.html/js        # 화면 캡처 영역 자르기 창
├── report.html/css/js  # 인쇄(PDF)용 오답노트 문서
├── lib/grading.js      # 정답지 파싱 · 채점 · 파트 집계 (순수 함수)
├── lib/store.js        # chrome.storage 래퍼 (확장 밖에선 localStorage로 대체)
├── lib/analysis.js     # 기록 → 약점 프로필 · 검색 신호 · LLM용 요약
├── lib/kb.js           # RAG 지식베이스: 유형별 공부법 자료 (자유롭게 추가/수정)
├── lib/retrieve.js     # 신호 + 메모 키워드 하이브리드 검색
├── lib/coach.js        # 프롬프트 구성
├── lib/openrouter.js   # OpenRouter 무료 모델 목록 · 스트리밍 채팅 · 오류 안내
├── lib/markdown.js     # 모델 응답 렌더링 (HTML 이스케이프)
└── tests/              # grading.test.mjs, coach.test.mjs
```

테스트: `node --test extension/tests/grading.test.mjs extension/tests/coach.test.mjs`

LangChain 대신 직접 구현한 이유: 이 확장은 빌드 없이 폴더째 설치하는 구조이고, MV3는 CDN 같은 원격 스크립트를 쓸 수 없어
LangChain.js를 넣으려면 번들러 빌드가 필요합니다. 지식베이스가 수십 개 규모라 임베딩 없이 메타데이터+키워드 검색으로 충분하며,
자료가 수백 개 이상으로 늘면 임베딩 검색으로 바꾸는 것을 고려하세요.

`lib/store.js`가 확장 밖에서는 localStorage를 쓰므로, `python -m http.server --directory extension` 으로 띄워 `sidepanel.html`을 일반 페이지로 열어서 UI를 확인할 수 있습니다(화면 캡처는 확장에서만 동작).
